## Ownership

`super-chat` owns the runtime, safety, lifecycle, and result contracts.
Hosts supply handlers for tools that depend on product data or platform APIs.

## 2026-09-06 Minimal Provider Integration

Completed the smallest provider-composition slice after a read-only survey of
`obsidian-ai`'s canonical registry, executor, turn coordinator, model-history,
and tool tests. `super-chat` now accepts one or several host tool capabilities,
resolves each tool name to its owning capability, rejects duplicate names, and
passes the active abort signal through adapter execution and the shared agent
loop. Existing single-provider adapters remain source-compatible.

This does not define or copy the 31 built-in Obsidian tools, and it does not
claim the full T25 runtime. Approval, cancellation, and existing execution
behavior remain in the current engine while the later extraction adds
structured results, evidence, retry, and audit behavior.
