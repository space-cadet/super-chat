## Objective

Extract obsidian-ai's three-tier memory and pruning behavior into a neutral,
host-backed capability usable by Arxivite, Obsidian, and standalone hosts.

## Subtasks

- [ ] **T26a** — Define the neutral memory-store contract and tier model.
- [ ] **T26b** — Implement short-term, staged, core, and archive memory behavior.
- [ ] **T26c** — Implement memory CRUD, search, audit, restore, and promotion tools.
- [ ] **T26d** — Implement AI pruning, deduplication, and safe recovery.
- [ ] **T26e** — Add host storage adapters and acceptance tests.

## Completion Criteria

- Memory is injected through shared context rules.
- Host storage remains outside shared core.
- Pruning is auditable, reversible, and never silently destructive.
- Arxivite and Obsidian can supply independent memory stores.
