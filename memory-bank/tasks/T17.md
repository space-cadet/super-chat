## Decision

The former task proposed making Arxivite's current `ChatEngine` feature path
the default by flipping its toggle. That would preserve Arxivite-owned chat
mechanics and is not the desired architecture.

The target is `SuperChatApp` mounted with `ArxiviteSuperChatHost`. T19 owns
that migration.

## Why the Old Plan Was Retired

The current intermediate path still makes Arxivite:

- Construct and coordinate the engine itself.
- Iterate stream events and accumulate assistant text.
- Save user and assistant messages separately.
- Maintain a parallel session linked by an untyped annotation.
- Handle tool events without a complete approval handshake.
- Ignore existing persistence and RAG adapters in active engine construction.

Making that path the default would entrench the wrong boundary.

## Preserved Value

The existing feature toggle remains useful as a reversible migration and
acceptance mechanism. Do not remove it until T19 passes completion criteria.
