# T13: Tool Result Formatting

*Created: 2026-05-19 14:10:00 IST*
*Last Updated: 2026-09-06 13:13:22 IST*

**Status**: ❌ **SUPERSEDED**
**Priority**: MEDIUM

## Details

The standalone formatter task is superseded by T25 and T16. Tool results now
require shared formatting, structured evidence, provenance, and context
budgeting rather than an Arxivite-specific formatter.

## Design

```typescript
// Formatters for common result types
function formatPapers(papers: RetrievedPaper[]): string;
function formatBookmarks(bookmarks: Bookmark[]): string;
function formatProfile(profile: UserProfile): string;
function formatSearchResults(results: SearchResult[]): string;

// Generic formatter
function formatToolResult(toolName: string, result: ToolResult): string;
```

## Replacement

- T25c — shared tool-result formatting and execution behavior.
- T25d — structured evidence-producing tool results.
- T16c — evidence ledger, provenance, and citations.

## Files
- `src/formatters/toolResultFormatters.ts`

## Notes
- Must produce markdown tables for structured data
- Must handle errors gracefully
- Must be customizable per-tool
- Must truncate long lists to avoid context overflow

## Acceptance Criteria
- [ ] Paper list renders as markdown table with title, authors, year
- [ ] Bookmarks render as bulleted list with links
- [ ] Errors render as clear error messages
- [ ] Long lists are truncated with "...and N more" suffix
