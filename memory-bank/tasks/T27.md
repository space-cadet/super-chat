## Objective

Provide host-agnostic attachment handling for Markdown, PDF, and image inputs,
including model-message conversion, persistence, provenance, and context
budgeting.

## Subtasks

- [ ] **T27a** — Define neutral attachment and document-part types.
- [ ] **T27b** — Implement Markdown and text attachment resolution.
- [ ] **T27c** — Implement PDF attachment resolution and source provenance.
- [ ] **T27d** — Implement image attachment resolution and provider capability checks.
- [ ] **T27e** — Integrate attachments with budgets, persistence, UI, and tests.

## Completion Criteria

- Hosts provide file/document access without leaking platform types.
- Attachments are bounded before provider submission.
- Attachment identity and provenance survive persistence and replay.
- Unsupported media produces a clear, typed result.
