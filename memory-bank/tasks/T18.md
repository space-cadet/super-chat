**Parent**: T22

## Objective

Run the complete `SuperChatApp` inside `obsidian-ai` through an
`ObsidianSuperChatHost` and `ObsidianToolProvider`, while preserving plugin
behavior throughout an incremental migration.

T15 moves reusable mechanisms into `super-chat`. T18 owns the product-side
adapter and final replacement of duplicate chat mechanics.

## Obsidian Host Responsibilities

- Vault/document reads and mutations.
- Active editor, selection, and workspace navigation.
- Obsidian markdown rendering, notices, menus, commands, and modals.
- Plugin settings and chat storage primitives.
- Secure credential access available to the plugin.
- Obsidian-specific sync, lifecycle, updater, and migration behavior.
- Product tool implementations and risk metadata.

## Migration Method

1. Implement host capabilities required by T22's first vertical slice.
2. Mount `SuperChatApp` behind a reversible development path.
3. Prove session reload, streaming, cancellation, one read tool, and one
   approval-required write tool.
4. Migrate capability groups from T15 one at a time.
5. Keep old and new paths comparable until each group reaches parity.
6. Remove superseded code only after automated and manual acceptance.
