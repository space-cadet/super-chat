## Current delivery status — 2026-11-21

Canonical format support is implemented. The user's inbound JSON transfer is
confirmed; reverse transfer and JSONL remain unverified, and Markdown import
is deferred. See [data parity](../implementation-details/obsidian-ai-data-parity.md)
and [session exchange](../implementation-details/session-export-import.md).

## Objective

Provide versioned, host-independent session export/import including tool
history, retrieval evidence, citations, and supported attachments.

## Subtasks

- [ ] **T30a** — Define the versioned session exchange schema.
- [ ] **T30b** — Implement Markdown and JSON export with tools and evidence.
- [ ] **T30c** — Implement import validation and conflict handling; exclude migration for the current format-parity slice.
- [ ] **T30d** — Add host integration and round-trip acceptance tests.

## Completion Criteria

- Exported sessions can be validated without executing tools.
- Imports preserve visible history, model history, tools, evidence, and citations.
- Schema migrations are explicit and recoverable.
- Hosts choose storage and download/share mechanisms.

## Archive and Document Export Slice — 2026-11-18

Added shared chat archive export/import utilities and the export interface,
with native Android document output through a Capacitor plugin. Shared and
standalone typechecks, package build, and Android debug build passed. Archive
round-trip, migration/conflict handling, tool-history fidelity, and imported
content recovery still need acceptance. Import must remain data-only and never
execute saved tool actions.

## Standalone Backup and Restore — 2026-11-19

Settings export/import is wired for standalone settings with credentials
omitted; imports restore supported sync selections and WebDAV preferences.
Saved chats support JSON and JSONL exchange, and clearing chat history first
creates a recovery copy. Android uses its native document host for file output;
browser and desktop use their selected download/document services. Settings
round trips, chat archive round trips, migrations/conflicts, and recovery after
restart remain unverified. Obsidian file migration and its rolling `data.json`
backups do not apply to IndexedDB.

## Accounts and collaborative conversations — 2026-11-21

See [T33](T33.md) and [accounts and collaboration](../implementation-details/accounts-and-collaboration.md). Planning only; acceptance remains open.
