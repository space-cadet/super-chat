## Objective

Provide versioned, host-independent session export/import including tool
history, retrieval evidence, citations, and supported attachments.

## Subtasks

- [ ] **T30a** — Define the versioned session exchange schema.
- [ ] **T30b** — Implement Markdown and JSON export with tools and evidence.
- [ ] **T30c** — Implement import validation, migration, and conflict handling.
- [ ] **T30d** — Add host integration and round-trip acceptance tests.

## Completion Criteria

- Exported sessions can be validated without executing tools.
- Imports preserve visible history, model history, tools, evidence, and citations.
- Schema migrations are explicit and recoverable.
- Hosts choose storage and download/share mechanisms.
