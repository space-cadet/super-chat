## Objective

Expose privacy-safe diagnostics for provider, agent, tool, retrieval, memory,
attachment, persistence, and host failures.

## Subtasks

- [ ] **T29a** — Define diagnostic event and snapshot schemas.
- [ ] **T29b** — Capture provider, agent, tool, retrieval, and persistence events.
- [ ] **T29c** — Add redaction, correlation IDs, and safe export.
- [ ] **T29d** — Add diagnostics UI and cross-host tests.

## Completion Criteria

- A failed turn can be traced without exposing secrets or private content.
- Diagnostics distinguish provider, tool, retrieval, and persistence failures.
- Hosts can add platform diagnostics through a neutral sink.
