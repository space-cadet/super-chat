## Objective

Provide optional shared provider-profile and model-switching behavior for
hosts that need it. This task is not required for Arxivite, which already has
its own provider/model system.

## Subtasks

- [ ] **T28a** — Define provider-profile and credential-reference contracts.
- [ ] **T28b** — Implement runtime provider/model switching between turns.
- [ ] **T28c** — Persist profile selection and provider-neutral model history.
- [ ] **T28d** — Add profile-picker UI and active-stream behavior.

## Relationship to Message Context

This task owns selection and switching only when a host chooses to use the
shared feature. It does not change the shared message-context rules or require
Arxivite to move provider/model selection into super-chat.

## Completion Criteria

- Hosts provide profiles and credentials without exposing secrets to sessions.
- Model changes apply without recreating the whole product chat workflow.
- Active-stream switching is cancelled or deferred safely.
- Profile/model state survives reload and passes cross-host tests.
